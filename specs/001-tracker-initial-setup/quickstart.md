## Install Dependencies

```bash
# Runtime dependencies
npm install antd date-fns

# Tailwind CSS v4 + Vite plugin
npm install -D tailwindcss @tailwindcss/vite
```

After installation, `package.json` runtime dependencies should include:
```json
{
  "dependencies": {
    "react": "^19.2.5",
    "react-dom": "^19.2.5",
    "antd": "^5.x.x",
    "date-fns": "^4.x.x"
  }
}
```

## Configure Tailwind CSS v4

### 1. Register the Vite plugin

```ts
// vite.config.ts
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';
import tailwindcss from '@tailwindcss/vite';

export default defineConfig({
  plugins: [
    react(),
    tailwindcss(),
  ],
});
```

### 2. Create the global stylesheet

```css
/* src/styles/globals.css */
@import "tailwindcss";

@theme {
  --color-pastel-mint: #d4f1e4;
  --color-pastel-peach: #fde8d8;
  --color-pastel-lavender: #e8e0f7;
  --color-pastel-sky: #d6eeff;
  --color-pastel-lemon: #fef9c3;
  --color-pastel-rose: #fce4ec;
  --color-surface: #fafafa;
  --color-surface-card: #ffffff;
  --color-text-primary: #1a1a2e;
  --color-text-muted: #6b7280;
  --color-urgent: #fde8d8;
  --color-urgent-border: #f97316;
}
```

### 3. Import the stylesheet in the entry point

```tsx
// src/main.tsx
import './styles/globals.css';
```

## TypeScript Strict Mode

Ensure `tsconfig.app.json` has strict mode on (already set in the base template):

```json

    "strict": true
  }
}
```
